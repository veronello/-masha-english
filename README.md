# Masha English

Простой сайт для мотивации и изучения английского. Первый этап — только каркас по рукописным эскизам.

## Согласованная структура

- About: пустая вкладка, сохранить на будущее.
- ЕГЭ Theory: короткие правила по грамматическим темам. Articles — пример структуры с блоками a/an, the, no article. Объяснения пока не добавлять.
- ЕГЭ Practice: пять предложений с ответами на выбранную грамматическую тему. Учебные материалы пока не добавлять.
- Random Stuff: пустая вкладка.
- Forum: пустая вкладка; функциональности форума пока нет.

В дальнейшем можно подбирать отдельные задания на одну тему из разных вариантов ЕГЭ. Полные экзамены не требуются. При подборе проверять соответствие формата и темы: нумерация может меняться по годам.

## Файлы

`dist/index.html`, `dist/style.css`, `dist/app.js` — статический сайт без зависимостей и сборки. Открывается напрямую через index.html; переходы используют URL hash. Темы, правила и упражнения задаются в массиве `topics` в app.js. Значения null оставлены намеренно. При добавлении ответа появится раскрываемая подсказка.

Репозиторий: https://github.com/veronello/-masha-english

Публикация сайта выполняется отдельно. Автоматическая синхронизация GitHub и опубликованного сайта не настроена.

## Оформление

Чисто белый фон страницы и блоков. Зелёные акценты: заголовки правил, линии, номера упражнений и активная вкладка. Основной текст нейтральный. Название и логотип в шапке убраны. Название темы выводится один раз, заголовком; отдельной контрастной кнопки-дубля нет. Это правило применяется к теории и практике.
