# Masha’s English

Простой мотивационный сайт для изучения английского. Дизайн по макету от 12 сентября 2026 года: белый фон, зелёные акценты, приветствие, книги, чашка и растение.

## Где добавить первое задание

Открой нужный файл в `dist/` и вставь HTML между комментариями внутри `<div class="lesson-content">`:

| Раздел | Файл |
| --- | --- |
| About | `dist/about.html` |
| Matching Headings | `dist/matching-headings.html` |
| Word Formation | `dist/word-formation.html` |
| Grammar in Context | `dist/grammar-in-context.html` |
| Random Stuff | `dist/random-stuff.html` |

Задания пока не добавлены: первое задание автор добавит самостоятельно. Обычный текст абзаца оборачивается в `<p>...</p>`, подзаголовок в `<h2>...</h2>`, список в `<ol><li>...</li></ol>`.

## Остальные файлы

- `dist/index.html`: главная страница. Кнопка и нижняя стрелка открывают Matching Headings, логотип возвращает на главную.
- `dist/style.css`: оформление и адаптация для телефона.
- `dist/assets/reference.webp`: предоставленный макет в веб-формате. CSS показывает только нужные области логотипа и иллюстрации, сохраняя их исходный вид. Текст приветствия и меню — обычный редактируемый HTML.
- `dist/favicon.svg`: значок вкладки.

Сайт статический: сборка и установка зависимостей не нужны. Можно скачать репозиторий и открыть `dist/index.html` в браузере.
